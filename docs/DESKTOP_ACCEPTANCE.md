# 桌面端验收清单

> 为什么要有这份文档：自动化测试覆盖的是**浏览器模式**和 **Rust 逻辑**，
> 真实 Tauri 窗口里的行为（托盘、通知、自启、快捷键、系统对话框）一行都没被覆盖过。
> 那些东西只能在真实 GUI 会话里点一遍。
>
> 用法：从 A 开始按顺序做。每一节写清「做什么 / 应该看到什么 / 看不到说明什么」。
> 一节一节记，别跳 —— 出问题时能立刻知道是哪一步开始不对。

## 0. 前置

```bash
cd D:\项目
npx tauri build --no-bundle        # 产物：src-tauri\target\release\desktop-ai-assistant.exe
npm run test:all                   # 全绿再开始
npm run doctor                     # 先分清「环境限制」和「项目问题」
```

日志位置（出错时先看这里）：

```
%LOCALAPPDATA%\com.example.desktop-ai-assistant\logs\desktop-ai-assistant.log
```

数据位置（设置、会话都在这个库里）：

```
%APPDATA%\com.example.desktop-ai-assistant\assistant.db
```

## A. 启动与窗口

| 步骤 | 应该看到 | 看不到说明什么 |
| --- | --- | --- |
| 双击 exe | 出现标题为「桌面 AI 助手」的窗口，居中，1180×780 | 窗口没出来 → 看日志最后几行 |
| 看日志 | `本地数据库就绪：…assistant.db` 和 `托盘图标已就绪` 各一行 | 少了「托盘图标已就绪」→ 托盘建失败，后面 B 不会生效 |
| 浏览器模式对照 | 浏览器里「托盘 / 自启 / 快捷键 / 文件 / 截屏 / 自动化」都显示为不可用 | 桌面版里如果也显示不可用 → `platform_capabilities` 漏了这一项 |

## B. 关闭窗口缩到托盘

**这是最容易「看起来没问题其实坏了」的一条。**

| 步骤 | 应该看到 | 看不到说明什么 |
| --- | --- | --- |
| 点窗口右上角 × | 窗口消失，**进程还在**（任务管理器里能看到） | 进程直接没了 → 没有缩到托盘 |
| 看日志 | `收到关闭请求：退出中=false 缩到托盘=true 托盘可用=true → HideToTray` 再一行 `窗口已隐藏到托盘` | 先确认使用的是当前构建的 exe 且设置开关已打开；旧 exe 没有诊断日志，不能据此判断监听是否触发 |
| 托盘图标（右下角，可能要展开 ^） | 能看到本应用的图标 | 没有图标 → 托盘建失败，看 A 的日志 |
| 双击托盘图标 | 窗口回来了 | 双击没反应 → `on_tray_icon_event` 没接上 |
| 右键托盘图标 | 菜单：显示主窗口 / 隐藏到托盘 / 分隔线 / 退出 | 菜单文案或项不对 |

## C. 托盘菜单

| 步骤 | 应该看到 |
| --- | --- |
| 托盘右键 → 隐藏到托盘 | 窗口消失，进程还在 |
| 托盘右键 → 显示主窗口 | 窗口回来 |
| 托盘右键 → 退出 | 进程真的退出（不是又缩回托盘） |

## D. 本地文件授权

| 步骤 | 应该看到 | 看不到说明什么 |
| --- | --- | --- |
| 设置页 → 本地文件 → 选一个文件夹 | 弹出系统选目录对话框 | 没弹窗 → `pick_directory` 命令没接上 |
| 选完之后卡片 | 显示完整路径 + 「已授权」 | 显示「未授权」→ 写入失败了 |
| 浏览目录 | 列出授权目录里的文件和子目录，能进能退 | 空列表 / 报错 → `list_authorized_directory` 的问题 |
| 点一个文本文件预览 | 显示内容 + 字节数 | 显示不出来 → `read_authorized_file` 的问题 |
| 手动删掉那个授权文件夹，再点浏览 | 明确说「授权目录不在了」，而不是空白 | 空白或崩 → 失败提示没做 |

## E. 截屏

| 步骤 | 应该看到 | 看不到说明什么 |
| --- | --- | --- |
| 设置页 → 截屏 → 打开开关 | 出现「抓一张试试」按钮 | 开关点不动 → 能力探测漏了 `screenshot` |
| 点「抓一张试试」 | 显示主屏截图 + 尺寸 + 体积 | 报错 → 看日志里的失败原因 |
| 关掉开关 | 预览图消失 | 图还在 → 关闭时没丢弃内存里的截图 |
| 检查磁盘 | 没有任何截图临时文件产生 | 有 → 「不落盘」这条破了 |

> 截图只截**主屏**。多屏机器上会提示「检测到 N 块屏幕，只截了主屏」—— 这是预期行为。

## F. 工具调用确认（需要有 API Key 且模型支持 function calling）

| 步骤 | 应该看到 | 看不到说明什么 |
| --- | --- | --- |
| 先在 D 里授权一个文件夹，把某个文件名记下来 | | |
| 聊天里说「帮我看看 <文件名> 里有什么」 | 模型先说一句「我看看」，然后输入框上方出现「模型想读一下这些内容」 | 什么卡都没有 → 模型没发工具调用（换个支持 function calling 的模型），或 `tools` 没传上去 |
| 观察准备阶段 | 可能出现「模型正在准备访问请求…」，逐个列出它要的东西 | 一直只有光标 → 进度事件没推到界面 |
| 点「不允许」 | 提示已允许 0 项 → 继续 → 模型说读不了 | 模型还在硬读 → 拒绝没作为工具结果发回去 |
| 再来一次，点「允许」 | 卡片变成「访问结果（1 项成功）」→ 模型接着回答 | 没有结果卡片 → 执行结果没记 |
| 说「读一下 ../../windows/win.ini」 | 卡片里出现这一项 → 允许 → **结果卡片里显示失败原因**（超出授权范围） | 真的读到了 → 路径校验破了，**这是严重问题** |
| 说「看看我的屏幕」 | 请求截屏 → 允许 → 模型能看到图 | 模型说「我看不到图」→ 截图没有作为消息带进去，或模型不支持视觉 |

> 截图那条还要求模型「支持图片输入」开关打开（设置页模型卡片里）。关着的话会被拦下并提示。

## G. 通知

| 步骤 | 应该看到 |
| --- | --- |
| 设置页 → 通知 → 打开「回复完成时通知」 | 开关能点、能存 |
| 切到别的窗口，发一条消息，等它答完 | 右下角弹出系统通知 |
| 窗口在前台时再发一条 | **不该**弹通知（前台不打扰） |

> 未安装、直接双击运行的 exe 可能因为缺 AppUserModelID 而不显示通知 —— 这是 Windows 的已知限制。

## H. 开机自启

| 步骤 | 应该看到 |
| --- | --- |
| 设置页 → 开机自启 → 打开 | 状态变成「已启用」 |
| 打开任务管理器 → 启动 | 能看到本应用 |
| 关掉开关 | 任务管理器里那一项消失 |

## I. 全局快捷键

| 步骤 | 应该看到 |
| --- | --- |
| 设置页 → 快捷键 → 录制一个组合键（比如 Ctrl+Alt+K） | 显示已注册 |
| 切到别的程序，按这个组合键 | 本应用窗口出现或隐藏 |
| 设一个系统已占用的组合键 | 明确提示「可能被别的程序占用」，而不是静默失败 |

## J. 自动化（键鼠模拟）

| 步骤 | 应该看到 |
| --- | --- |
| 设置页 → 自动化 → 打开开关 | 出现动作列表编辑区 |
| 没有截图时 | 提示「先到截屏卡片抓一张」 |
| 抓一张截图后 | 图显示出来，能点「取点」在图里取坐标 |
| 加：移动 → 点击 → 等待 → 输入 | 每加一条，预览区多一行人话描述 |
| 不加点击直接加输入 | 明确提示「输入之前必须先有点击」 |
| 点「执行…」 | 弹确认框，逐条列出动作 + 「请把手从鼠标上拿开」 |
| 确认之后 | 3 秒倒计时，然后真的开始动鼠标 |
| 执行中 | 有「停止」按钮，点了能停下 |
| 执行完 | 出现执行报告，逐条列出做了哪几步 |
| 关掉开关再执行 | 被拒绝，并说明去哪里打开 |

> 第一次试**别拿重要窗口**：找个空记事本或文本编辑器，确认整条链路通了再动别的。

## K. 重置与凭据

| 步骤 | 应该看到 |
| --- | --- |
| 设置页 → 数据 → 重置本地数据 | 有确认框，说明不可恢复 |
| 确认之后 | 会话清空、设置回默认、**两个高风险开关都回到关闭** |
| 检查凭据 | API Key 仍然在系统凭据管理器里（重置数据不删凭据）或明确说明会删——以界面文案为准 |
