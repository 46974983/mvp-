# 桌面 AI 助手 · 界面演示 Demo

对应《PRODUCT_DESIGN.md》的界面流程演示版。**所有数据都是模拟的**，不调用真实模型，只用来验证「整体界面 + 操作流程」是否合理。

## 快速开始

```bash
# 1. 启动本地预览（需要 Node.js 18+）
node serve.mjs

# 2. 浏览器打开
#    http://localhost:5173
```

> ⚠️ 不能直接双击 `index.html`——浏览器禁止在 `file://` 协议下加载 ES Module，必须走 HTTP。

## 目录结构

```
├── index.html          页面骨架（聊天页 + 设置页 + 弹窗）
├── styles.css          全部样式，浅色/深色主题只换 CSS 变量
├── app.js              界面逻辑：渲染 + 交互
├── serve.mjs           零依赖本地预览服务器
├── src/
│   └── mock-data.js    模拟数据层（将来接真后端只改这里）
└── tests/
    ├── mock-data.test.mjs   数据层测试（23 个用例）
    ├── ui-flow.check.mjs    界面流程验证（35 项检查，需 Chrome）
    └── screenshots/         流程验证时自动截图
```

## 能体验的流程

对应设计文档第 2 节的 MVP 闭环：

1. **配置模型**（设置页）：填 API 地址 / Key / 模型名 → 「测试连接」（模拟成功或给出具体错误提示）→ 保存
2. **发起聊天**（聊天页）：新建会话 → 输入消息 → 回车发送
3. **查看流式回答**：逐字输出，可随时点「停止」，保留已生成部分
4. **会话管理**：自动以首条消息命名、重命名、删除（带确认）、自动恢复最近会话
5. **人格配置**：改助手名称，回聊天页看头像变化
6. **数据持久化**：刷新页面后配置和会话都在（浏览器 localStorage）
7. **浅色 / 深色主题**：右上角 ◐ 切换，记忆选择

## Demo 边界（有意为之）

- 回复内容是固定文案池，按输入哈希挑选，不联网
- 「测试连接」不发真实请求，只按校验规则假装成功/失败
- 数据存浏览器 localStorage，不是 SQLite
- Markdown 只支持 Demo 用到的语法（粗体/代码块/引用/列表）

这些边界的意义：**界面和数据结构已按真实形态设计**，接真后端时只替换 `src/mock-data.js` 内部实现，界面层零改动。

## 运行测试

见上文「已验证」一节。改动任何代码后，两个测试都要重新跑一遍并全部通过。
